# Оценка моделей

Текущий эталон: `gold_400_for_metrics/gold_400_v3.jsonl`, 400 фото, 361 рамка, 122 пустых кадра. Предыдущие результаты на 364 рамках находятся в `history/metrics_gold_v2`.

Запуск из корня: `python eval/scripts/evaluate.py`. Зависимости и команды визуализации описаны в корневом README. Оценщик использует максимальное паросочетание рамок при IoU >= 0,5 / 0,75. При равном числе пар максимизируется сумма IoU. TP/FP/FN суммируются по набору, затем вычисляется object micro-F1.

Доверительные интервалы: 2000 повторов бутстрепа по фотографиям, seed 20261119, процентили 2,5 и 97,5. Это интервалы для данного gold, без учёта неопределённости эталонных меток.

`results/leaderboard.csv` содержит семь конфигураций. `by_group`, `by_category`, `by_count`, `recall_by_size`: срезы. `fp_on_empty`: ложные срабатывания на пустых фото. `per_photo`: подробный расчёт. `threshold_curve`: анализ чувствительности порога по тому же набору. Максимум кривой не является независимой тестовой оценкой.

Время в лидерборде: отдельно среднее и медиана, без прогрева и повторных обработок. Детекторные пороги фильтруют один набор кандидатов. Три кадра Qwen с повторами перечислены в `results/summary.json`. Аппаратная среда основного прогона: Apple M3/MPS. Версии библиотек указаны в метаданных запусков.

`by_gold_source` группирует по происхождению эталона. Группы различаются по сложности, это не эксперимент по сравнению разметчиков.

Ошибка прежнего gold на 7775492 и 16391324 исправлена по замечанию Kmdmrg с проверкой исходных наблюдений. Удалены три рамки, фотографии сохранены. Максимальное изменение F1@0,5 среди семи конфигураций 0,003535. Лидер Qwen прежний.
