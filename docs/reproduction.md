# Воспроизведение

## Проверка сохранённого результата

Все семь конфигураций и экзаменационные предсказания уже сохранены. Проверка пакета и пересчёт метрик выполняются командами из корневого README без инференса. Две правки gold не меняли модели, исходные снимки или их ответы. Для проверки независимости bbox/review служит `scripts/validate_package.py`.

В `crowd/code/` сохранены алгоритмы экзамена и передачи в review, включая проверки повторных операций. Тесты используют синтетические данные и моки:

```bash
python crowd/code/test_bbox_exam.py
python crowd/code/test_review_transfer.py
```

Пулы проекта завершены. Проверки выполняются локально по сохранённым ответам. Для нового сбора разметки потребуется токен Яндекс Заданий и отдельные пулы.

## Исходные фотографии

`data/main.jsonl` содержит окончательный набор 400 ID и SHA-256 изображений, использованных при инференсе. `python scripts/download_dataset.py` скачивает оригиналы и сверяет хеши. Уже проверенные файлы пропускаются. Лицензии всех записей CC0. Фотографии сохраняются в `models/inaturalist_dataset/photos/final/` и не включаются в Git.

Для иллюстраций `eval/scripts/download_images.py` получает уменьшенные large-версии. Их нельзя подставлять вместо оригиналов в повторный инференс, если требуется воспроизвести исходные размеры.

## Модели

Код инференса и зависимости находятся в `models/`. Оригинальный запуск сделан на macOS/MPS. Для инференса код использует `fcntl`, поэтому нужен macOS/Linux (на Windows: WSL/Linux, либо отдельная адаптация блокировки файла). Сам пересчёт метрик проверен на Windows/Python 3.12.

Из каталога `models/`, после установки соответствующих `requirements-models.txt` / `requirements-qwen-macos.txt`, можно сделать новый прогон на окончательном manifest:

```bash
python scripts/run_models.py --model dino --input inaturalist_dataset/main_final.jsonl --output reruns/dino/candidates.jsonl --revision a2bb814dd30d776dcf7e30523b00659f4f141c71
python scripts/run_models.py --model owlv2 --input inaturalist_dataset/main_final.jsonl --output reruns/owlv2/candidates.jsonl --revision cfd3195ba4ea9592eec887ded089f4c08eff231d
python scripts/run_models.py --model qwen --input inaturalist_dataset/main_final.jsonl --output reruns/qwen/candidates.jsonl --revision 89644892e4d85e24eaac8bacfd4f463576704203
```

Точные параметры и сырые ответы исходного эксперимента лежат в `models/results/*/*.meta.json`. Для детекторов экспортируйте пороги 0,15/0,25/0,40 через `scripts/export_predictions.py`. Для Qwen требуется проверка полноты ответа, техническую ошибку нельзя считать пустым результатом.

Историческая политика Qwen: 512 токенов, изображение до 768 px, детерминированная генерация. Четыре оборванных ответа повторены целиком с 4096 токенами/1024 px, один обработан по фрагментам. Два таких кадра затем заменены. В окончательном main остались три полнокадровых повтора. Код, промпт и сырые результаты сохранены в `models/results/qwen`.

Экзамен хранится отдельно в `contest/`, включая исходную конфигурацию, 400 полных ответов, журналы и минимальную посылку `predictions.jsonl`. Рамки посылки вручную не исправлялись. Для основного прогона сохранены raw_text, параметры, ошибки и повторы. Полный stdout первоначального запуска отсутствует.

## Измерение времени и параметры вывода

Время включает препроцессинг, инференс, постобработку и синхронизацию устройства. Скачивание изображений и загрузка весов в него не входят. Пороговые варианты детекторов получены фильтрацией одного набора кандидатов. DINO и OWLv2 запускались с PyTorch 2.7, Qwen с PyTorch 2.15.

Qwen выдаёт координаты текстом без confidence, сопоставимого с оценками детекторов. В поле уверенности сохранено `null`. Таксоны и ожидаемые классы изображений в запросы моделям не передавались.
