Исходные предсказания до замены трёх фотографий

Итоговый набор находится в ../model_results_400/, его метрики в ../eval/results/.
Этот каталог сохраняет результаты на первоначальных 400 фото из main.jsonl.

Основные файлы: dino_t0.25.jsonl, owlv2_t0.25.jsonl, qwen.jsonl.
Файлы t0.15 и t0.40: эксперимент с порогом для DINO и OWLv2.
В каждом файле 400 строк, включая фото без найденных объектов (boxes: []).

Формат: photo_id. boxes: left/top/width/height от 0 до 1 относительно
исходного фото. scores. elapsed_seconds. warmup.
У Qwen scores=null для каждой рамки: сопоставимой уверенности нет.
Эталон для итоговой оценки находится в ../gold_400_for_metrics/gold_400_v3.jsonl.

Модели: Grounding DINO tiny (IDEA-Research/grounding-dino-tiny),
OWLv2 base (google/owlv2-base-patch16-ensemble), Qwen3-VL-2B-Instruct.
DINO: butterfly. moth.. Порог текста 0.25. OWLv2: a photo of a butterfly /
a photo of a moth. Для обоих NMS IoU 0.5, один класс бабочек и мотыльков.
Qwen: взрослые бабочки и мотыльки, без гусениц, куколок и других насекомых.
Исходный запуск Qwen: 768 px, максимум 512 токенов, без sampling.

Qwen: 395 исходных полных ответов сохранены. Фото 615002914, 12297798,
76337845, 339831709 повторно обработаны той же моделью: 1024 px,
4096 токенов, repetition penalty 1.1, промпт с запретом повторять рамки.
Фото 247404664 обработано по 16 фрагментам (4x4, расширение ячейки на 10%
с каждой стороны), 768 px, 1024 токена, penalty 1.15. Координаты пересчитаны
на оригинал, NMS IoU 0.5 с приоритетом рамок дальше от края фрагмента.
Все повторные ответы завершены и помечены completion_method. После
замен фотографий в итоговом наборе осталось три полнокадровых повтора.

Время: препроцессинг + инференс + постпроцессинг + синхронизация устройства,
без скачивания и загрузки весов. MacBook Air M3, 16 GB, MPS;
PyTorch 2.7 для DINO/OWLv2 и 2.15 для Qwen. При расчёте скорости исключаются warmup=true. У пяти дообработанных фото elapsed_seconds: исходный
вызов + успешный повтор (для фрагментов сумма вызовов). Компоненты сохранены
отдельно. Время неуспешной полнокадровой попытки не записано и не включено.
Повторно обработанные фото исключаются из сравнения скорости исходных конфигураций.
Варианты порога получены из одного запуска: время инференса у них одинаковое.
