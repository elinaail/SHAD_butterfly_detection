# Эталон для оценки

Файл `gold_400_v3.jsonl` содержит 400 фотографий, 361 рамку и 122 пустых кадра. Координаты записаны в формате xywh и нормированы на размеры изображения.

Версия `gold_400_v2.jsonl` сохранена для сравнения. В v3 удалены три рамки вокруг ручейников на фотографиях 7775492 и 16391324. Причины исправлений и проверка исходных наблюдений находятся в `corrections_v3.json` и `evidence/`. Состав фотографий между v2 и v3 не менялся.

`main_metadata_v2.json` содержит ID, URL оригиналов, наблюдения iNaturalist, лицензии CC0 и категории отбора. Номер версии этого файла относится к составу фотографий. Три замены исходных кадров описаны в `replacements.json`.

## Происхождение разметки

Исходные рамки проверяли отдельные исполнители Яндекс Заданий. Авторы bbox исключались из review своих фотографий. Ответы сохранены в `../crowd/responses/`, последующие исправления и их причины в `../crowd/adjudications/`.

В `gold_400_provenance.json` используются три источника:

| Метка | Источник |
|---|---|
| `crowd` | Разметка исполнителей |
| `captain_review` | Разбор спорных кадров, организованный капитаном, в том числе с помощью LLM |
| `Meow` | Ручная разметка участника команды |

Часть исправлений после review подготовлена с помощью LLM. Эти решения хранятся отдельно от человеческих ответов и не добавляются к голосам проверяющих. Независимая человеческая перепроверка охватывала не все окончательные правки. Это отражено полями `independent_human_verification_of_new_boxes: false` и `independent_human_review_of_revision: false` в журналах.

Поле `models_under_evaluation_used: false` указывает, что сравниваемые модели не использовались для принятия соответствующего решения. Помощь другой LLM при разборе отмечена отдельно. Остаточные ошибки эталона могут влиять на метрики моделей.
