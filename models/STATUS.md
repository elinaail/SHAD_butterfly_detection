# Исходный прогон моделей

Этот файл описывает прогон до трёх замен фотографий. Итоговые предсказания находятся в `../model_results_400/`, метрики по проверенному эталону в `../eval/results/`.


На всех 400 фотографиях из `inaturalist_dataset/main.jsonl` получены результаты
Grounding DINO tiny, OWLv2 base и Qwen3-VL-2B-Instruct. Сохранены рамки,
уверенности детекторов, время каждого вызова, SHA-256 исходных фото и настройки.

Для DINO и OWLv2 выгружены варианты порога 0.15, 0.25 и 0.40. Основной
вариант: 0.25. Остальные предназначены для эксперимента с порогом.
Файлы для оценки перечислены в MODELS.md.

## Особенность Qwen

В итоговом `results/qwen/predictions.jsonl`: 400 завершённых результатов.
395 первоначальных полных ответов сохранены без изменений. Пять ответов,
оборванных на 512 токенах, дообработаны повторным инференсом той же модели.

Четыре фото дали полный JSON при лимите 4096 токенов. Фото 247404664
обработано по 16 перекрывающимся фрагментам. Сохранены все полные исходные
ответы, границы фрагментов и правило объединения рамок. Для этого фото
единого полнокадрового `raw_text` нет: ответы находятся в `tiles`.
Настройки и ограничения сравнения описаны в MODELS.md.

ID дообработанных фото: 615002914, 12297798, 247404664, 76337845, 339831709.
Исходные обрывы сохранены в `results/qwen/candidates.jsonl`. Рамки получены
автоматически, без ручной коррекции. Оценка итогового набора находится
в `../eval/results/`.

## Проверка

- По 400 уникальных photo_id у каждой модели, наборы полностью совпадают с main.
- Хеши исходных фото совпадают у всех моделей и с локальными оригиналами.
- Проверены границы рамок, уверенности, положительное конечное время работы.
- Проверены все 7 итоговых файлов и соответствие порогам.
- Проверены полные ответы повторных запусков и преобразование координат фрагментов.
- Отдельно проверено, что 395 прежних полных ответов Qwen не изменились.
- 8 тестов проходят. Машинный результат проверки: `results/validation.json`.
  Воспроизведение: `python3 scripts/validate_results.py` (нужны локальные фото).

Прогон выполнен на MacBook Air M3 / 16 GB / MPS. Версии runtime указаны
в metadata и MODELS.md. Результаты привязаны к исходному main.jsonl с хешем
`311806f590f0e49b4bdbd4a3aa250d90051766604a5fddd8b48afefe286e51f2`.
