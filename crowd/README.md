# Разметка и независимый review

Проекты: [bbox 11767](https://tasks.yandex.ru/requester/project/11767), [review 11768](https://tasks.yandex.ru/requester/project/11768). Доступ к кабинетам зависит от аккаунта; их снимки настроек доступны в `config/`.

Этапы: экзамены → пилот 20 фото → основной bbox 380 → независимый review → разбор разногласий → три согласованные замены с новым bbox/review → итоговый gold. После анализа моделей исправлены два ошибочных эталона ручейников без удаления фотографий.

В `responses/` сохранены исходные статусы, задания, ответы и время. Идентификаторы исполнителей последовательно заменены на `worker_NNN`, данные владельца удалены. Координаты и вердикты не менялись. `tasks/` содержит реальные страницы и исключения авторов; `candidates/` связывает bbox с review.

Исторические хеши ответов относятся к оригинальным локальным выгрузкам до обезличивания. Хеши содержимого публичных экзаменационных эталонов обновлены после нормализации полей происхождения. Исходные локальные выгрузки сохранены у капитана.

Экзамены: bbox 6866117 (навыки 21393/21394), review 6866119 (навык 21395). Правила bbox-геометрии и пограничных случаев в `code/bbox_exam.py`. Экзамен review включает 10 контролей на одной странице, основной допуск от 90. Точные фильтры/таймеры/цены всех пулов в `config/`.

В основном bbox 5 фото на странице, перекрытие 1, 2,50 ₽/страница. Review: 4 обычных + 1 контроль, перекрытие 2, 1 ₽/страница. Исключаются все участвовавшие в bbox этого фото, а не только автор принятого ответа. Два ответа используются для проверки кандидата, при несогласии требуется отдельный разбор.

Основной review: 760 обычных ответов на 380 фото, 183/190 правильных контрольных ответов, 330 фото приняты обоими, 50 потребовали разбора. Дополнительно просматривались визуально подозрительные кадры. Согласие ревьюеров не является оценкой истинной точности gold.

`audits/` — датированные исторические снимки, их промежуточные статусы не описывают текущее состояние gold. Итоговый расход 650,30 ₽, включая комиссию 40%, из 850 ₽. Детали в `budget.json`. Повторно открывать законченные пулы для воспроизведения не нужно.

Три замены согласованы с преподавателем 18 ноября из-за непроверяемых границ плотных колоний и экстремального макрокадра. История исходных сложных кадров сохранена. Замены прошли те же этапы, все модели получили одинаковые новые изображения.
